# 会計理論ドリル

名城大学 経営学部「簿記・会計特別入学試験」対策用の理論記述トレーニング。
`index.html` を**ブラウザで開くだけ**で動く。サーバ・ビルド・npm 依存はない。

このディレクトリは本体リポジトリ（簿記・会計資格対策アプリ）の
コンテンツ制作パイプラインとは独立している。`validate.py` / `seed/topics.json` の
論点タグ体系には接続していない。

## 著作権の扱い

**条文の本文は一切含まない。** アプリが持つのは次の3つだけ。

1. 設問文（独自に記述したもの）
2. 採点要素（条文の引き写しではなく、要点を再構成したもの）
3. 出典表示（文書名＋条番号＋権利者）と、確認できた場合のみ公式ページへのリンク

企業会計原則・同注解／連続意見書／原価計算基準は企業会計審議会、
企業会計基準第9号・第10号は企業会計基準委員会（© 公益財団法人 財務会計基準機構）による。

スクレイピングも実行時 fetch も行わない。外部リソースの読み込みはゼロ。

## 検証

```
# JS 構文チェック（index.html から script を抜き出してから）
node -e 'const fs=require("fs");fs.writeFileSync("/tmp/app.js",fs.readFileSync("index.html","utf8").match(/<script>([\s\S]*)<\/script>/)[1])'
node --check /tmp/app.js

# 計算28問の正解値を、問題データを参照しない独立実装で再計算して突合
node verify_calc.js        # → 28件中28件一致 / exit 0
```

`verify_calc.js` は設問の前提条件だけから正解値を組み立て、`index.html` からは
`id` と `answer` しか読まない。両者が同じ誤りを共有しない構造にしてある。
配賦額の合計が製造間接費実際発生額に一致すること、製造間接費差異の三分法の合計が
総差異に一致することも内部チェックしている。

## 未解決の事項

- **出典URLは原価計算基準の1本しか持てていない。** 企業会計原則・同注解、
  企業会計基準第9号・第10号、連続意見書 第三・第四 の公開ページURLは未解決。
  制作時のセッションは外向き通信が遮断されており、`www.asb-j.jp` を含む全ホストへの
  到達が egress ポリシーで拒否された（`example.com` すら不可）。
  推測でURLを組み立てることはせず、条番号のみ表示している。
- 原価計算基準のURLとアンカー（SPEC §2-1 記載）も、**このセッションでは到達確認できていない。**
  過去に人間が確認したという記載に依拠して採用している。
- **採点要素の会計的な正確性は未検証。** 条文を参照できないまま書いている。
  `REVIEW.md` に33問分の要素を出典条番号つきで並べてあるので、
  会計法規集と突き合わせてレビューすること。

`REVIEW.md` は `node gen_review.js` で `index.html` から自動生成する。手で編集しない。
